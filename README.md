# RELATÓRIO DE RESULTADO - VENDAS INTERNET
Esse relatório é resultado ao longo do mês.
_____________________________________________________________________________________________________________________________________

📊 Excel + SQL – Relatório do Adventure Works.

Este projeto apresenta um dashboard desenvolvido no SQL + EXCEL para uma empresa fictícia do setor de Vendas, Receita e Custo, analisando a performance dos valores da empresa nos ano 2013.
_____________________________________________________________________________________________________________________________________

📈 Principais Análises
_____________________________________________________________________________________________________________________________________
* Números de Receita e Custo  Por País ( Receita Total e Custo Total)

* Números de Vendas por Gênero (Masculino e Feminino)
_____________________________________________________________________________________________________________________________________

🛠️ Ferramentas Utilizadas
_____________________________________________________________________________________________________________________________________
* SQL
* Power Query
* Excel
* Modelagem e tratamento de dados
